# Tank UI Online-Vorschau

https://xmarsup.github.io/#spin

Weitere Ansichten: [Halloween-Pass](https://xmarsup.github.io/#pass), [Shop](https://xmarsup.github.io/#shop), [Inventar](https://xmarsup.github.io/#inventory/tanks).

Dieses Repository enthaelt einen kompilierten statischen Frontend-Export mit Grafiken und Schrift. Das Roblox-Spiel-Repository und seine Servermodule bleiben privat.

Die Vorschau nutzt ein Testprofil im lokalen Browser-Speicher. Keine Verbindung mit Roblox-Konten, Spielservern oder echten Kaeufen.

244 Web-Tests bestanden. preview-meta.json dokumentiert den Export. Lokale Windows-Herkunftspfade und alte Vorlagen-/Referenzseiten wurden aus dem oeffentlichen Export entfernt.

Neue gepruefte Exporte aktualisieren dist; GitHub Actions veroeffentlicht sie auf derselben Pages-Adresse. Der lokale Vite-Server wird nicht automatisch synchronisiert.
