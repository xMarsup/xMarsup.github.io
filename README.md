Dieses Repository enthaelt einen kompilierten statischen Frontend-Export mit Grafiken und Schrift. Das Roblox-Spiel-Repository und seine Servermodule bleiben privat.

Die Vorschau nutzt ein Testprofil im lokalen Browser-Speicher. Modes zeigt eine Vorschau; Roblox-Spielbeitritte und echte Kaeufe sind nicht angebunden.

244 Web-Tests bestanden, alle147 Asset-Adressen geprueft; zusaetzlich11 aktuelle Navigations-/Routentests. preview-meta.json dokumentiert den Export. Originalgrafiken, Fonts und Fenstergeometrie unveraendert. Lokale Windows-Herkunftspfade und alte Vorlagen-/Referenzseiten wurden aus dem oeffentlichen Export entfernt.

Neue gepruefte Exporte aktualisieren dist; GitHub Actions veroeffentlicht sie auf derselben Pages-Adresse. Der lokale Vite-Server wird nicht automatisch synchronisiert.
